# Early Detection of Parkinson’s Disease – Bi-LSTM + GRU Fusion

This repository contains **all code, configuration, and documentation** needed to
reproduce the experiments reported in our study:

> **Early Detection of Parkinson’s Disease using a Bi-LSTM & GRU Multimodal Fusion Model**  
> Alishba Z. Abbasi · et al., 2025

Key features
* **Multimodal pipeline** – MRI images (PPMI) + speech recordings (Oxford & PC-GITA)
* **Hybrid architecture** – parallel Bi-LSTM and GRU branches with late fusion
* **Fully reproducible** – Conda environment, deterministic seeds, ready-made scripts
* **Public-data only** – no patient-identifiable information committed
